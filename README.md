# 易画本地测试版

这是一个在本机运行的礼盒主视觉设计原型。测试者使用自己的 API Key，项目与图片只保存在自己的电脑。

## 只需两步

1. 双击 `启动本地测试.command`。
2. 首次启动按弹窗提示：未安装 Node.js 时点击下载；安装完成后再次双击，并填入自己的 API Key。

网站会自动在浏览器中打开： [http://127.0.0.1:4175/](http://127.0.0.1:4175/)

## 使用流程

1. 在首页填写课程文案、视觉选项、画幅与卖点组件。
2. 按需要上传讲师、角色/IP、参考图和徽章。
3. 创建任务，进入工作台后调用 Skill 生成 Prompt。
4. 审核 Prompt 后生成图片；确认主视觉后可继续生成延展物料。
5. 下载合成图或将确认项目发布为首页预设。

## 注意

- 测试环境为 macOS，需 Node.js 22+；启动时会自动检查并打开官方下载页。
- API Key 只写入测试者本地的 `.env` 文件，不会被上传。
- `data/` 和 `uploads/` 会在首次运行时自动创建，保存该测试者自己的项目数据与图片。
- 若 4175 端口已有易画服务，脚本会直接打开已运行的网站。
- 若需更换 API Key，关闭服务后删除 `.env`，再次双击启动脚本即可重新填写。
